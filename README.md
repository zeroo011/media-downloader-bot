# 🚀 Universal Media Downloader Telegram Bot

Современный, высокопроизводительный и отказоустойчивый Telegram-бот на **Python 3.12+ (aiogram 3.x)** для скачивания видео, аудио, фото и каруселей практически с любых интернет-ресурсов в максимальном доступном качестве.

---

## 🌟 Основные возможности

* **🎥 Скачивание видео в Full HD / 4K:**
  - YouTube (видео, Shorts, поддержка cookies).
  - TikTok и Douyin (без водяных знаков, с оригинальным звуком).
  - Instagram (Reels, видеопосты, карусели).
  - VK Видео и Клипы.
  - Rutube, Дзен Видео.
  - Twitter / X, Twitch клипы, Pinterest, Likee, Coub.
* **🖼 Поддержка фото и каруселей:**
  - Полное скачивание фото-слайдшоу из TikTok и каруселей Instagram альбомами (до 25 фото).
  - Прямое моментальное скачивание любых фото по прямым ссылкам (JPG, PNG, WEBP, GIF).
  - Кнопка **«📁 Файлом (без сжатия)»** для получения исходного файла без потерь качества Telegram.
* **🎵 Аудиодорожки и музыка:**
  - Скачивание треков из SoundCloud.
  - Извлечение звука (MP3 320 kbps) из любого видео по команде `/audio <ссылка>` или кнопкой под готовым видео.
  - Извлечение оригинальной аудиодорожки из слайдшоу TikTok.
* **⭕ Видеосообщения («кружочки»):**
  - Конвертация любого видео длительностью до 60 секунд в круглые видеосообщения Telegram (команда `/round <ссылка>` или кнопка).
* **⚡ Inline-режим (`@bot_username <ссылка>`):**
  - Возможность отправлять видео, аудио и карусели фото прямо в любые групповые чаты и личные сообщения через инлайн-поиск.
  - Быстрое кэширование на базе SQLite: повторно запрошенные медиафайлы отправляются мгновенно без повторного скачивания.
* **🌐 Раздача файлов больше 50 МБ:**
  - Если видео или аудио превышает лимит Telegram Bot API (50 МБ), бот генерирует безопасную временную ссылку (действует 7 минут) со встроенного веб-сервера.
* **🛡️ Защита сервера и отказоустойчивость:**
  - Интеллектуальная параллельная очередь воркеров с динамическим отображением позиции пользователю.
  - Активная защита от переполнения диска: квоты на временные файлы и автоматическая аварийная очистка.
  - Защита от SSRF и локальных IP-адресов.
  - Защита от спама и DoS.

## 📋 Системные требования

* **ОС:** Ubuntu 20.04 / 22.04 / 24.04 LTS, Debian 11 / 12
* **CPU:** от 1 vCPU (рекомендуется 2 vCPU для комфортной конвертации FFmpeg)
* **RAM:** от 1 ГБ (скрипт автоматически настроит 2 ГБ SWAP, если оперативной памяти < 2 ГБ)
* **Диск:** от 10 ГБ свободного пространства
* **Утилиты:** `ffmpeg`, `python3` (3.10+), `git`, `curl` (устанавливаются автоматически через `install.sh`)

## ⚡ Быстрая установка в одну команду

Склонируйте репозиторий и запустите интерактивный скрипт установки:

```bash
git clone https://github.com/zeroo011/media-downloader-bot.git /opt/mega-bot
cd /opt/mega-bot
sudo bash install.sh
```

### Что делает скрипт `install.sh`:
1. Устанавливает системные пакеты (`python3`, `python3-venv`, `python3-pip`, `ffmpeg`, `git`, `curl`).
2. Запрашивает токен бота (`BOT_TOKEN`) и ID администратора (`ADMIN_ID`) с проверкой формата.
3. **Опциональная настройка Caddy и домена:** запрашивает доменное имя, автоматически устанавливает веб-сервер **Caddy**, генерирует reverse proxy и выпускает бесплатный **Let's Encrypt SSL (HTTPS)** для мгновенных превью в Inline-режиме Telegram.
4. Сканирует аппаратные ресурсы сервера (CPU, RAM, диск).
5. При нехватке памяти (< 2 ГБ RAM) автоматически предлагает и настраивает **2 ГБ SWAP**.
6. Рассчитывает оптимальный профиль производительности (Low / Medium / High) и лимиты воркеров.
7. Создает изолированное виртуальное окружение `venv` и ставит зависимости.
8. Генерирует файл `.env` с безопасными правами доступа (`chmod 600`).
9. Регистрирует и запускает **systemd-сервис** с автоматическим перезапуском при сбоях.

## ⚙️ Переменные окружения (`.env`)

Все параметры можно отредактировать в файле `.env`:

| Переменная | Обязательная | По умолчанию | Описание |
|---|---|---|---|
| `BOT_TOKEN` | **Да** | — | Токен бота от [@BotFather](https://t.me/BotFather) |
| `ADMIN_ID` | **Да** | `0` | Числовой Telegram ID главного администратора |
| `BOT_USERNAME` | Нет | Авто-детект | Юзернейм бота (определяется через API автоматически) |
| `WEB_BASE_URL` | Нет | `http://IP:8080` | Внешний URL для скачивания файлов > 50 МБ и инлайн-режима |
| `WEB_PORT` | Нет | `8080` | Порт встроенного веб-сервера aiohttp |
| `DATA_DIR` | Нет | `./data` | Путь к папке базы данных и постоянных файлов |
| `NUM_WORKERS` | Нет | `2` | Количество параллельных потоков скачивания |
| `FFMPEG_THREADS` | Нет | `1` | Количество потоков процессора для FFmpeg |
| `MAX_FILE_SIZE_MB` | Нет | `200` | Максимальный размер скачиваемого файла (МБ) |
| `MIN_FREE_DISK_GB` | Нет | `2.0` | Минимальный резерв свободного места на диске (ГБ) |
| `WEB_TTL_SECONDS` | Нет | `420` | Время жизни ссылок на веб-скачивание (7 минут) |
| `CACHE_TTL_SECONDS` | Нет | `240` | Время жизни кэша конвертации (4 минуты) |

## 🛠 Управление сервисом (systemd)

После установки бот работает в фоновом режиме через systemd под именем `mega-bot`:

```bash
# Проверить статус работы
sudo systemctl status mega-bot

# Посмотреть живые логи в реальном времени
sudo journalctl -u mega-bot -f -n 50

# Перезапустить бота
sudo systemctl restart mega-bot

# Остановить бота
sudo systemctl stop mega-bot

# Запустить бота
sudo systemctl start mega-bot
```

## 🍪 Обход проверок YouTube (Cookies)

Если YouTube блокирует сервер дата-центра проверкой на робота (*Sign in to confirm you're not a bot*), экспортируйте cookies из браузера:
1. Установите расширение для браузера (например, *Get cookies.txt LOCALLY* для Chrome/Firefox).
2. Авторизуйтесь на YouTube и экспортируйте cookies в формате Netscape.
3. Поместите файл на сервер в директорию данных бота:
   ```bash
   cp cookies.txt /opt/mega-bot/data/cookies.txt
   sudo systemctl restart mega-bot
   ```
